Cyber Bullying Text Detector

Overview

A Machine Learning-based web application that detects and classifies cyberbullying text using Natural Language Processing (NLP) techniques. The system helps identify harmful online content and promotes safer digital communication.

Features

- Detects cyberbullying content from text input
- Machine Learning prediction model
- Web interface built with Flask
- Real-time text classification
- User-friendly design

Technologies Used

- Python
- Flask
- Scikit-Learn
- HTML
- CSS
- JavaScript

Project Structure

- model/ - Trained machine learning model and dataset
- templates/ - HTML templates
- static/ - CSS and JavaScript files
- app.py - Main Flask application
- requirements.txt - Project dependencies

Installation

pip install -r requirements.txt

python app.py
